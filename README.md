# Tic-Tac-Toe with p5.js

This is a simple Tic-Tac-Toe game built using [p5.js](https://p5js.org/). The game allows two players to take turns playing on a 3x3 grid. The first player to align three of their symbols (X or O) in a row, column, or diagonal wins the game.

## 🛠 Features

- Interactive Tic-Tac-Toe grid
- Player turns are indicated dynamically
- Highlights winning combinations
- Declares the winner when applicable

## 🚀 How to Play

1. Open the game in a browser.
2. Click on any empty cell to place your move (X or O).
3. The game alternates turns between Player One (X) and Player Two (O).
4. The winner is displayed when a player successfully aligns three marks in a row, column, or diagonal.
5. If all cells are filled and no player has won, the game declares a draw.

## 📦 Installation & Running Locally

1. Clone the repository:
   ```sh
   git clone https://github.com/AsfandYar-Ktk/tictactoe-p5-js.git
   ```
2. Navigate to the project directory:
   ```sh
   cd tictactoe-p5-js
   ```
3. Open `index.html` in your browser to play the game.
